# Dokumentasi Folder Lib - PresensiKu

Folder `lib` berisi kode utama aplikasi PresensiKu yang dikembangkan menggunakan Flutter dan bahasa pemrograman Dart.

## Struktur File

- **main.dart**: Titik awal aplikasi dan pengaturan navigasi.
- **app_data.dart**: Menyimpan data yang digunakan aplikasi, termasuk data siswa dan mata pelajaran.
- **attendance_store.dart**: Mengelola data catatan presensi siswa.
- **jadwal_store.dart**: Mengelola data guru dan jadwal pelajaran.
- **screen/dashboard_screen.dart**: Halaman dashboard aplikasi.
- **screen/guru_screen.dart**: Halaman pengelolaan data guru.
- **screen/jadwal_screen.dart**: Halaman pengelolaan jadwal pelajaran.
- **screen/kelas_screen.dart**: Halaman data kelas.
- **screen/siswa_screen.dart**: Halaman data siswa.
- **screen/presensi_screen.dart**: Halaman pencatatan kehadiran siswa.
- **screen/riwayat_screen.dart**: Halaman riwayat presensi.
